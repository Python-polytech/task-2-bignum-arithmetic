# Реализовать длинную арифметику для целых чисел с операциями сложения, вычитания, умножения и целочисленного деления

Программа реализует класс для арифметических операций (+, −, *, //) над числами в произвольной системе счисления (от 2 до 36) с контролем разрядности и обрезкой результата при переполнении.

### 1. Клонирование репозитория
```bash
git clone https://github.com/Python-polytech/task-2-bignum-arithmetic.git
cd task-2-bignum-arithmetic
```

### 2. Создание и запуск виртуального окружения
#### Для Windows:
```bash
# Создание окружения
python -m venv venv
# Активация окружения
.\venv\Scripts\activate
```

#### Для macOS и Linux:
```bash
# Создание окружения
python3 -m venv venv
# Активация окружения
source venv/bin/activate
```

## Запуск
В директории **task-2-bignum-arithmetic/** выполнить команду
```bash
python main.py
```

При запуске программа выводит текстовое меню в консоли, позволяя настроить основание системы счисления и разрядность, а затем выполнять арифметические операции над вводимыми числами.
